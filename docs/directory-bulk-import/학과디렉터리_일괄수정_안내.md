# 학과 디렉터리 일괄 수정 양식 — 작성 안내

첨부된 **`학과디렉터리_일괄수정_양식.csv`** 에 목록을 작성해 업로드하시면,
학과·세부전공을 한 번에 추가·수정할 수 있습니다. (엑셀에서 편집 → **"CSV UTF-8(쉼표로 분리)"** 로 저장)

> ⚠️ 이 양식으로는 **텍스트 정보만** 일괄 변경됩니다.
> **학과 이미지** 는 기존 관리자 화면에서 개별로 관리합니다. (삭제도 개별 화면에서)

---

## 두 가지 작성 방식 (선택)

업로드한 행을 "기존 항목 수정"으로 볼지 "신규 추가"로 볼지 판단하는 기준이 다릅니다.
**어느 쪽이 편하신지 알려주시면 그 방식으로 맞추겠습니다.** (시스템은 두 방식을 모두 지원합니다.)

### 방식 1 — 내보내기 → 편집 → 업로드 (권장)
- 관리자 화면에서 **"현재 디렉터리 내보내기"** 를 누르면 `id`가 채워진 파일을 받습니다.
- 그 파일에서 **고치고 싶은 값만 바꿔** 다시 업로드합니다.
- `id`가 있는 행 → 그 항목을 **수정**, `id`가 빈 행 → **신규 추가**.
- 이름을 바꿔도 안전하고, 같은 항목이 중복 생성될 위험이 없습니다.

### 방식 2 — 빈 양식에 직접 작성
- `id` 열은 **비워둔 채** 이름부터 직접 채웁니다.
- 학과는 **(계열 + 학과명)**, 세부전공은 **(상위학과 + 전공명)** 이 기존과 같으면 **수정**, 없으면 **신규 추가**.
- 손으로 작성하기 쉽지만, 이름에 오타가 있으면 다른 항목으로 잘못 추가될 수 있고,
  이름 자체를 바꾸는 수정은 할 수 없습니다(새 항목으로 인식).

---

## 열(컬럼) 설명

| 열 | 필수 | 설명 |
|---|---|---|
| **id** | 방식1 수정 시 | 시스템 식별 번호. 내보내기 파일엔 자동으로 채워져 있습니다. 신규 행은 **비워두세요**. |
| **구분** | ✅ | `학과` 또는 `세부전공` |
| **상위학과** | 세부전공만 ✅ | 세부전공이 속한 학과명. (학과 행은 비움) |
| **계열** | 학과만 ✅ | `인문·사회` / `자연과학` / `공학` / `예술` / `체육` / `의학`. (세부전공은 상위학과를 따르므로 비움) |
| **학과명/전공명** | ✅ | 학과 행이면 학과명, 세부전공 행이면 전공명 |
| **모집여부** | | `Y`(모집) / `N`(미모집). 비우면 기존값 유지(신규는 Y). |
| **홈페이지** | | 홈페이지 주소 (https://...) |
| **위치** | | 예) 인문대 교수연구동 109호 |
| **전화** | | 예) 051-510-1509 |
| **BK21참여** | | `Y` / `N` |
| **BK21사업단명** | | BK21 참여 시 사업단 이름 |
| **BK21홈페이지** | | BK21 사업단 홈페이지 주소 |
| **해시태그** | | 쉼표(,)로 구분. 예) `#영어교육,#문법교육` (엑셀에선 한 칸에 입력) |
| **소개** | | 한 줄 소개 |

### 작성 규칙
- **빈 칸은 "기존 값 유지"** 로 처리합니다(실수로 비워도 기존 정보가 지워지지 않음).
  값을 일부러 지우려면 관리자 화면에서 직접 비워주세요.
- 세부전공 행은 **상위학과**가 (기존 또는 같은 파일 내 신규) 학과로 인식돼야 합니다.
- 업로드 즉시 반영이 아니라, **"추가 N건 · 수정 M건" 미리보기를 확인한 뒤** 적용됩니다.
  미리보기에서 **한글이 깨져 보이면** 적용하지 말고, 엑셀에서 "CSV UTF-8"로 다시 저장해 올려주세요.
- 형식 오류가 있는 행은 미리보기에 표시되고, 그 행만 건너뜁니다.

## 첨부 예시 파일의 행
1. `국어국문학과` (학과, id=1) — **기존 학과 수정** 예시 (BK21 참여)
2. `외국어교육학과` (학과, id=34) — **기존 학과 수정** 예시
3. `영어교육학` (세부전공, id=1, 상위학과=외국어교육학과) — **기존 세부전공 수정** 예시
4. `인공지능학과` (학과, id 비움) — **신규 학과 추가** 예시
5. `데이터사이언스전공` (세부전공, id 비움, 상위학과=인공지능학과) — **신규 세부전공 추가** 예시

> 4·5번은 예시이므로 실제 작성 시 지우고 사용하세요.
