# 학과 디렉터리 정리 번들 — 협동과정·계약학과 제거 (2026-06-12)

> ※ nginx 리다이렉트와 한 번에 적용하려면 `deploy/rollout-2026-06-12/` (통합 번들) 사용.
> ※ `images.tar.gz`(was 이미지)는 통합 번들 폴더로 이동됨 — 단독 실행 시 DB 정리만 수행.

## 무엇을 하나
'학석사 연계과정 안내 > 04 학과 디렉토리'에서 **협동과정(32개)·계약학과(19개)를 계열·목록째
삭제**한다. 근거: 학석박사 연계과정 신청 불가 학과 — 대학원혁신실 회신.

학과 디렉터리는 **DB가 원본**(레포 JSON은 최초 1회 시드용)이라 코드 재배포만으로는 라이브가
안 바뀜 → 이 번들이 라이브 DB에서 직접 삭제한다. 공개 페이지의 계열 탭/목록은 모두 API
데이터에서 만들어지므로 DB 삭제 즉시 사이트에 반영된다(앱 재시작 불필요).

- 삭제 전 두 테이블(dir_departments, dir_majors) 전체를 서버에 자동 백업 → 한 줄로 복구 가능
- 삭제는 단일 트랜잭션 — 중간 실패 시 DB는 그대로
- 폴더에 `images.tar.gz`(새 was 이미지)가 있으면 그것도 같이 적재·기동함
  (관리자 화면 계열 드롭다운 정리 + 시드 JSON 정리 반영. 없으면 DB 정리만 — 공개 사이트
  반영은 그걸로 충분)

## 실행 방법 (화이트리스트 IP PC에서)
1. **이 폴더 통째로** 복사 (USB/메신저)
2. (권장) SSH 개인키 `id_ed25519`를 폴더 안에 같이 넣기 — 자동 감지·권한 교정.
   없으면 비밀번호 프롬프트 2번 (서버 비번: deploy/DEPLOYMENT.md 자격증명)
3. **`apply.bat` 더블클릭**. 끝.
   - Git Bash 불필요 — Windows 10(1809+)/11 기본 내장 ssh/scp/curl만 사용

## 성공 판정
마지막 출력:
```
   학과 수: 96 / 협동과정·계약학과 잔존: 0 (기대 0)
   ...
 완료. 학과 디렉터리에서 협동과정·계약학과가 제거됨.
```
(96은 2026-06-12 기준 — 그 사이 관리자가 학과를 추가/삭제했으면 달라질 수 있음. 잔존 0이 핵심)
